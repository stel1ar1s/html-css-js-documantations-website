Specyficzność Jak przeglądarka rozstrzyga konflikty stylów

Specyficzność CSS to ważny temat, szczególnie w dużych projektach. Jest to mechanizm, którego przeglądarka używa do ustalenia, które style zastosować do elementu, gdy ten element podlega sprzecznym regułom CSS z różnych selektorów. To w istocie system priorytetów dla reguł CSS.

Im wyższa specyficzność selektora, tym większy priorytet będzie miał i jego style zostaną zastosowane, ignorując style o niższej specyficzności. Specyficzność liczy się jako czterocyfrowa wartość (A, B, C, D), gdzie każda pozycja odpowiada określonemu typowi selektora. Żadna liczba selektorów niższego poziomu nie przebije jednego selektora wyższego poziomu.

Znaczenie ma też pozycja w samym pliku CSS: jeśli specyficzność jest identyczna, wygrywa reguła zadeklarowana później.

Poziomy specyficzności, od najwyższego do najniższego
Poziom Co się liczy Przykład Waga
A — styl liniowy Styl w atrybucie style elementu HTML style="color: red" 1,0,0,0
B — identyfikatory Liczba selektorów #id #main-nav 0,1,0,0
C — klasy, atrybuty, pseudoklasy Liczba selektorów klas (.class), selektorów atrybutów ([type="text"]) i pseudoklas (:hover, :first-child) .active[data-state="open"]:hover 0,0,3,0
D — elementy i pseudoelementy Liczba selektorów elementów (p, h1, div) i pseudoelementów (::before, ::after) div p::first-line 0,0,0,2

Ważne, żeby to zrozumieć: im więcej klas i pseudoklas dopisujemy, tym wyższa specyficzność. Do tej samej klasy można odwołać się dwukrotnie — jeśli napiszemy .example.example {}, specyficzność wyniesie 0,0,2,0.

Przypadki szczególne i wyjątki:

  • Selektor uniwersalny i kombinatory. Selektor * oraz kombinatory >, +, ~ mają specyficzność 0 — nie wpływają na obliczenia. Na przykład div > p ma specyficzność 0,0,0,2.
  • Pseudoklasa :not(). Sama w sobie nie dodaje specyficzności, ale przejmuje specyficzność selektorów znajdujących się w jej środku. Na przykład div:not(.special) ma specyficzność 0,0,1,1 (jedna klasa + jeden element).
  • Pseudoklasa :is(). Przyjmuje specyficzność najbardziej specyficznego selektora ze swoich argumentów. Na przykład :is(#id-test, .class-test) będzie miało specyficzność 0,1,0,0 (specyficzność #id-test).
  • Pseudoklasa :where(). Zawsze ma specyficzność zerową (0,0,0,0). Jest to przydatne przy tworzeniu stylów, które łatwo nadpisać.

Wpływ !important. Słowo kluczowe !important jest specjalnym wyjątkiem od reguł specyficzności i należy używać go bardzo rzadko. Ignoruje ono wszystkie wcześniejsze obliczenia specyficzności — reguła z !important będzie miała priorytet nad każdą inną regułą (włącznie z selektorami #id i stylami liniowymi), która go nie zawiera.

Jeśli dwie reguły zawierają !important, wygrywa ta o wyższej specyficzności początkowej. Gdy specyficzność jest równa, wygrywa reguła zadeklarowana później w kodzie.

Unikaj !important — utrudnia późniejsze debugowanie i utrzymanie kodu. Używaj go tylko w ostateczności. Współcześnie lepszym narzędziem do porządkowania priorytetów są warstwy kaskady (@layer) oraz zerowanie specyficzności przez :where().

Reguła rozstrzygająca (tie-breaker). Jeśli dwa selektory mają dokładnie tę samą specyficzność, stosuje się zasadę kolejności: wygrywa reguła zadeklarowana później w arkuszu stylów.

#id Selektor po identyfikatorze

Odwoływanie się do elementów w CSS może odbywać się na różne sposoby. Omówmy wszystkie przykłady i sposoby wybierania elementów HTML w CSS, zaczynając od odwołania po identyfikatorze id.

Identyfikator musi być unikalny w obrębie całej strony. Selektor #id ma wysoką specyficzność (0,1,0,0), dlatego w praktyce do stylowania używa się klas — id zostawia się dla zakotwiczeń w adresie URL, powiązań <label for> i odwołań z JavaScriptu. 

<p id="for-id-example">Przykład</p>

<style>
  #for-id-example {
    color: red;
  }
</style>

[atrybut] Selektor po atrybucie

Odwoływanie się po atrybucie — elementy HTML mogą mieć różne atrybuty. Po nich możemy odwołać się do wszystkich elementów, które mają takie same atrybuty. Omówmy to na przykładzie.

Selektor [atrybut] dopasowuje sam fakt obecności atrybutu, a [atrybut="wartość"] — dokładną wartość. Specyficzność jest taka sama jak klasy (0,0,1,0).

Uwaga na zasięg: selektor [type="text"] zadziała na każde pole tekstowe na stronie, nie tylko w tym przykładzie. Dlatego w podglądzie poniżej te same reguły zostały zawężone do kontenera przykładu — inaczej pokolorowałyby całą dokumentację. 
<input type="text">
<input type="number" placeholder="Wiek">

<style>
  [type="text"] {
    border: 1px solid red;
  }
  [type="number"] {
    border: 1px solid red;
  }
  [placeholder] {
    color: darkblue;
  }
</style>

Podgląd

[atrybut*="…"] Dopasowanie fragmentu wartości atrybutu

Odwoływanie się przez dopasowanie fragmentu wartości atrybutu. Jest kilka wariantów i każdy działa inaczej:

  • [href*="hh.pl"] — odwołujemy się do wszystkich elementów, które zawierają w sobie hh.pl, nawet jeśli obok jest wiele innych znaków. Jeśli w wartości występuje hh.pl, element podpada pod selektor.
  • [href^="https"] — używając dopasowania ^=, wybieramy elementy z atrybutem href, które zaczynają się od https.
  • [href$=".pl"] — wybieramy elementy, które kończą się na .pl.
  • [alt~="kot"] — analogicznie do dopasowania *=, w którym szukamy dowolnych, nieoddzielonych znaków w atrybucie, tutaj można szukać całych słów. Pod dopasowanie podpadną atrybuty, w których występuje oddzielone spacją słowo „kot”.
  • [class|="warning"] — można też wybrać po słowie, od którego zaczyna się klasa, po którym następuje dywiz, albo gdy słowo od razu się kończy i jest jedyną wartością.
  • [class*="cat" i] — flaga i na końcu odpowiada za ignorowanie wielkości liter w dopasowaniu.
Wszystkie reguły w podglądzie są zawężone do kontenera przykładu. Gdyby zostały zapisane globalnie — jak w próbce kodu — [href^="https"] pokolorowałby każdy link zewnętrzny w całej dokumentacji. 
<!-- 1. Zawiera fragment: *= -->
<a href="hh.pl">Link</a>
<a href="https://hh.pl">Link</a>

<style>
  [href*="hh.pl"] {
    background-color: red;
  }
</style>

<!-- 2. Zaczyna się od: ^= -->
<a href="https://pl">Link</a>
<a href="https://pl.com">Link</a>

<style>
  [href^="https"] {
    background-color: red;
  }
</style>

<!-- 3. Kończy się na: $= -->
<a href="https://google.pl">Link</a>
<a href="https://google.de">Link</a>
<a href="https://google.fr">Link</a>

<style>
  [href$=".pl"] {
    background-color: yellow;
  }
  [href$=".de"] {
    background-color: white;
  }
  [href$=".fr"] {
    background-color: blue;
  }
</style>

<!-- 4. Całe słowo oddzielone spacją: ~= -->
<img src="./img/cat.jpg" alt="kot niekot" width="80" height="59">

<style>
  [alt~="kot"] {
    background-color: yellow;
  }
</style>

<!-- 5. Słowo albo słowo z dywizem: |= -->
<a class="warning" href="#">Link</a>
<a class="warnings" href="#">Link</a>
<a class="warning-link" href="#">Link</a>

<style>
  [class|="warning"] {
    background-color: red;
  }
</style>

<!-- 6. Bez rozróżniania wielkości liter: flaga i -->

<a class="CAT" href="#">Link</a>

<style>
  [class*="cat" i] {
    background-color: blue;
  }
</style>

* Selektor uniwersalny

Selektor * nadaje jakiś styl wszystkim elementom na stronie. Często używa się go do zerowania stylów, na przykład do ustawienia box-sizing: border-box dla całego dokumentu.

Jego specyficzność wynosi 0, więc każda inna reguła go nadpisze. Warto pamiętać, że * ustawia właściwość bezpośrednio na każdym elemencie, a to przerywa dziedziczenie — dlatego font ustawia się zwykle na body, a nie przez *. 

*,
*::before,
*::after {
  box-sizing: border-box;
}

Ta reguła działa globalnie, więc nie ma sensu pokazywać jej w izolowanym podglądzie — jej efekt widać w całym projekcie.

A B Selektor potomka (zagnieżdżenie)

Można odwoływać się do elementów znajdujących się wewnątrz innych elementów. Spacja między selektorami oznacza „dowolny potomek”, na dowolnym poziomie zagnieżdżenia — nie tylko bezpośrednie dziecko. 

<p>
  <a href="#">
    <span>Tekst</span>
  </a>
</p>

<style>
  /* Żeby odwołać się do linku wewnątrz akapitu: */
  p a {
    background-color: red;
  }

  /* Żeby zejść jeszcze głębiej, do elementu span: */
  p a span {
    background-color: blue;
  }
</style>

A, B, C Kilka selektorów naraz

Odwołanie do kilku elementów jednocześnie. Przecinek rozdziela niezależne selektory, a wspólny blok deklaracji zostanie zastosowany do każdego z nich.

Ważne: każdy selektor z listy liczy swoją specyficzność osobno. Zapis h1, h2, h3 to trzy niezależne reguły o specyficzności 0,0,0,1, a nie jedna reguła o specyficzności 0,0,0,3. 

<h1>Niebo</h1>
<h2>Niebo</h2>
<h3>Niebo</h3>

<style>
  h1,
  h2,
  h3 {
    background-color: black;
    color: wheat;
  }
</style>

.a.b Element z dwiema klasami

Odwołanie do elementów, które mają dwie klasy lub więcej. Może istnieć kilka elementów z tą samą klasą, ale jeden z nich może mieć jeszcze jedną klasę. Aby odwołać się właśnie do tego elementu, który ma dodatkową klasę, trzeba zapisać selektory bez spacji, jeden po drugim.

Brak spacji jest tu kluczowy: .under-footer.footer to jeden element z dwiema klasami, a .under-footer .footer (ze spacją) to potomek. Specyficzność takiego zapisu wynosi 0,0,2,0. 

<a href="#" class="under-footer">Tylko jedna klasa</a>
<a href="#" class="under-footer footer">Dwie klasy</a>

<style>
  .under-footer.footer {
    background-color: yellow;
  }
</style>

A > B Bezpośrednie dziecko

Aby odwołać się do bezpośredniego elementu potomnego, używa się kombinatora >. W przeciwieństwie do selektora potomka (spacji) dopasuje on wyłącznie dzieci pierwszego poziomu, pomijając głębiej zagnieżdżone elementy. 

<section>
  <h2>Element, do którego się odwołujemy</h2>
  <div>
    <h2>Element, do którego się nie odwołujemy</h2>
  </div>
</section>

<style>
  /* Tylko bezpośrednie dzieci elementu section */
  section > h2 {
    background-color: red;
  }
</style>

display block, inline, inline-block, none

Właściwość display to prawdopodobnie najważniejsze narzędzie w CSS. Określa „reguły gry” dla elementu: jak będzie wyglądał, jak zajmie przestrzeń i jak będzie współdziałał z sąsiednimi elementami.

  • display: block (blokowy). Element zajmuje całą dostępną szerokość (rozciąga się od krawędzi do krawędzi) i zawsze zaczyna się od nowego wiersza. Można zadawać szerokość (width) i wysokość (height); odstępy (margin, padding) działają ze wszystkich stron. Domyślnie: div, p, h1, section.
  • display: inline (liniowy). Element zajmuje tylko tyle miejsca, ile ma w sobie treści. Nie przenosi się do nowego wiersza, a idzie w linii z tekstem. Szerokość i wysokość są ignorowane. Pionowe odstępy (margin-top / margin-bottom) zwykle nie działają i nie odpychają sąsiednich elementów. Domyślnie: span, a, b.
  • display: inline-block (liniowo-blokowy). Hybryda. Element stoi w linii (jak inline), ale można sterować jego rozmiarami i odstępami (jak w block). Często używany do przycisków, ikon lub kart, które mają stać obok siebie.
  • display: none. Używany do wyłączenia elementu. Element przestaje istnieć w układzie i nie jest w ogóle renderowany. Jest też niedostępny dla czytników ekranu — jeśli treść ma pozostać dostępna, a tylko zniknąć wizualnie, użyj klasy visually-hidden. 
.item {
  display: block;        /* blokowy */
  /* display: inline;       liniowy */
  /* display: inline-block; liniowo-blokowy */
  /* display: none;         całkowicie ukryty */
}

display: flex Podstawy Flexboxa

Istota: układ jednowymiarowy — kontrolujemy elementy albo w poziomie, albo w pionie.

Do czego: idealnie nadaje się do wyrównywania elementów w wiersz, centrowania treści i rozdzielania przestrzeni między przyciskami menu. To dziś „złoty standard” przy budowie komponentów. Po nadaniu kontenerowi display: flex element staje się blokowy, a elementy w jego wnętrzu układają się wzdłuż osi głównej jako elementy elastyczne (flex items).

display: inline-flex — przy tej wartości sam kontener staje się liniowy i dopasowuje się do szerokości oraz wysokości elementów w swoim wnętrzu.

Warto od razu poznać dwa pojęcia, bo wracają we wszystkich kolejnych właściwościach: oś główna (main axis) to kierunek ustawiony przez flex-direction, a oś poprzeczna (cross axis) jest do niej prostopadła. justify-content działa na osi głównej, a align-items na poprzecznej. 

<div class="flex-container">
  <div class="flex-item">Element</div>
  <div class="flex-item">Element</div>
  <div class="flex-item">Element</div>
</div>

<style>
  .flex-container {
    display: flex;
  }
  .flex-container .flex-item {
    border: 1px solid black;
    color: brown;
    background-color: gray;
  }
</style>

flex-direction Kierunek osi głównej

flex-direction służy do zadania kierunku, w jakim układają się bloki wewnątrz kontenera flex. Istnieje kilka wartości:

  • row — wartość domyślna; elementy wewnątrz kontenera układają się od lewej do prawej.
  • row-reverse — odwrotnie: elementy zaczynają się od prawej i idą w lewo.
  • column — elementy ustawiają się w kolumnie, jeden po drugim.
  • column-reverse — elementy zaczynają się od dołu i idą do góry.
Odwrócenie kierunku zmienia tylko kolejność wizualną. Kolejność odczytu przez czytnik ekranu i kolejność przechodzenia klawiszem Tab zostają takie jak w HTML — dlatego row-reverse nie powinien służyć do zmiany logicznej kolejności treści. 
.container-row {
  display: flex;
  flex-direction: row;
}
.container-row-reverse {
  display: flex;
  flex-direction: row-reverse;
}
.container-column {
  display: flex;
  flex-direction: column;
}
.container-column-reverse {
  display: flex;
  flex-direction: column-reverse;
}

flex-wrap Zawijanie elementów do nowej linii

  • flex-wrap: nowrap — wartość domyślna dla kontenera flex. Przy tej wartości, nawet jeśli elementy fizycznie nie mieszczą się w zadanym rozmiarze kontenera, nie będą przenoszone do nowej linii, a zaczną się ściskać.
  • flex-wrap: wrap — żeby ściskanie nie występowało, trzeba nadać tę wartość; wtedy elementy będą się przenosić od lewej do prawej i schodzić w dół.
  • flex-wrap: wrap-reverse — elementy nadal idą od lewej do prawej, ale nowe linie powstają od dołu do góry.

Dla wszystkich tych właściwości istnieje zapis skrócony flex-flow, który łączy flex-direction i flex-wrap: flex-flow: column wrap albo flex-flow: row-reverse wrap. 

.container-nowrap {
  display: flex;
  flex-wrap: nowrap;
}
.container-wrap {
  display: flex;
  flex-wrap: wrap;
}
.container-wrap-reverse {
  display: flex;
  flex-wrap: wrap-reverse;
}

/* Zapis skrócony: kierunek + zawijanie */
.container-flow {
  display: flex;
  flex-flow: row wrap;
}

flex-grow Rozciąganie elementów

flex-grow to właściwość, która określa, jak element ma się rozciągać, żeby wypełnić wolne miejsce w kontenerze.

Zasada działania: jeśli w kontenerze jest zbędna przestrzeń, elementy z flex-grow większym od zera dzielą ją między siebie proporcjonalnie do swoich współczynników.

  • flex-grow: 0 — wartość domyślna; element nie rośnie.
  • flex-grow: 1 — ważna wartość. Jeśli nadać ją wszystkim elementom, rozciągną się na całą dostępną im szerokość.
  • Proporcje: element z flex-grow: 2 otrzyma dwa razy więcej wolnego miejsca niż element z flex-grow: 1.

Jeśli przy tym nadać jednemu z elementów flex-grow: 2, będzie się starał zająć dwa razy więcej szerokości. Ale słowo kluczowe to „starał się” — może tego nie zrobić, bo dzielona jest tylko wolna przestrzeń, a nie cała szerokość kontenera. Dlatego pewniej jest nadawać wyższy współczynnik jednemu wybranemu elementowi. 

.container {
  display: flex;
}
.item-0 {
  flex-grow: 0;   /* wartość domyślna — element nie rośnie */
}
.item-1 {
  flex-grow: 1;   /* zajmuje całą wolną przestrzeń */
}
.item-2 {
  flex-grow: 1;
}
.item-3 {
  flex-grow: 2;   /* dwa razy więcej wolnej przestrzeni niż .item-2 */
}

flex-basis Rozmiar bazowy elementu

flex-basis to właściwość, która określa początkowy rozmiar elementu, zanim zacznie się on rozciągać (flex-grow) albo ściskać (flex-shrink).

  • Wartość domyślna: auto — rozmiar zależy od treści albo od właściwości width / height.
  • Co można podać: dowolne jednostki długości (px, %, em, rem) albo słowa kluczowe.
  • Priorytet: jeśli podano zarówno width, jak i flex-basis, dla Flexboxa priorytet ma flex-basis.
  • Różnica między auto i 0: flex-basis: auto bierze za podstawę rozmiar treści albo zadaną szerokość, a flex-basis: 0 ignoruje rozmiar treści (traktuje go jako zerowy), co pozwala rozdzielać przestrzeń między elementy maksymalnie równomiernie.

Kierunek, w którym działa flex-basis, zależy od flex-direction: przy row zachowuje się jak szerokość, a przy column jak wysokość. 

.row-container {
  display: flex;
  background-color: lightblue;
}
.column-container {
  display: flex;
  flex-direction: column;
  background-color: lightblue;
}
.item {
  width: 50px;
  height: 50px;
  color: darkblue;
  background-color: gray;
  border: 1px solid black;

  /* flex-basis ma priorytet nad width w kontenerze flex */
  flex-basis: 100px;
}

flex-shrink Ściskanie elementów

Całkowite przeciwieństwo flex-grow. flex-shrink wskazuje elementowi, jak mocno ma się ściskać względem pozostałych elementów.

Domyślnie wszystkie elementy mają flex-shrink: 1. W praktyce zwykle używa się flex-shrink: 0, żeby elementy zajmowały dokładnie tyle miejsca, ile im zadano, i nie ignorowały swoich wymiarów.

grow, shrink, basis. Do zadania tych trzech parametrów można użyć skróconej właściwości flex — wartości podaje się właśnie w tej kolejności. Najczęstsze zapisy to flex: 1 (czyli 1 1 0%) oraz flex: 0 0 auto. 

.item {
  flex-shrink: 2;   /* ściska się dwa razy szybciej niż element z wartością 1 */
}

/* Zapis skrócony: grow | shrink | basis */
.item-flex {
  flex: 0 0 200px;  /* nie rośnie, nie ściska się, bazowo 200px */
}

order Kolejność elementów

Właściwość order daje możliwość zadania kolejności elementu w kontenerze flex. Wartością 1 możemy przenieść element na koniec, a wartością -1 — na początek.

Domyślnie wszystkie elementy mają order: 0 i układają się w kolejności z HTML. Elementy sortowane są rosnąco po wartości order, a przy równych wartościach decyduje kolejność w kodzie źródłowym.

.container {

  order: 1;    /* na koniec */
}
.order--1 {

justify-content Wyrównanie w osi głównej

justify-content odpowiada za wyrównanie elementów wewnątrz kontenera flex wzdłuż osi głównej. Jeśli flex-direction: row, czyli wartość standardowa, będzie to rozmieszczenie elementów w poziomie; jeśli flex-direction: column — odpowiednio w pionie.

  • flex-start — elementy układają się od początku kontenera.
  • flex-end — elementy układają się na końcu kontenera.
  • center — elementy układają się na środku kontenera.
  • space-between — elementy odepchną się od siebie na jednakową, największą możliwą odległość; pierwszy przykleja się do początku, ostatni do końca.
  • space-around — podzieli kontener na tyle części, ile jest w nim elementów, i umieści elementy na środku tych części. Odstęp przy krawędziach jest o połowę mniejszy niż między elementami.
  • space-evenly — odstęp od początku, między elementami i na końcu będzie jednakowy, czyli elementy odepchną się równo zarówno od siebie, jak i od krawędzi. 
.container {
  display: flex;

  /* justify-content: space-between;  równo między, bez odstępu na krawędziach */
  /* justify-content: space-around;   równo wokół każdego elementu */
  /* justify-content: space-evenly;   identyczne odstępy wszędzie */
}

align-content Wyrównanie całych linii

align-content zarządza nie poszczególnymi elementami, a całymi liniami treści. Działa dopiero wtedy, gdy kontener ma flex-wrap: wrap i powstała w nim więcej niż jedna linia — przy jednej linii nie zmienia niczego.

  • space-between — pierwszy wiersz zostanie u góry, a drugi przemieści się na dół.
  • stretch — wiersze będą się rozciągać jednakowo i zajmą tę samą przestrzeń.
  • flex-start — wszystkie wiersze ustawią się od początku.
  • flex-end — wiersze ustawią się na dole.
  • center — wiersze ustawią się na środku.
  • space-around — podzieli kontener na tyle części, ile jest w nim wierszy, i umieści je na środku tych części.

padding Odstępy wewnętrzne

padding to odstępy wewnętrzne elementu. Dodaje wolną przestrzeń wewnątrz bloku, która przy domyślnym modelu pudełkowym dolicza się do zadanej wysokości i szerokości elementu. Treść nie będzie wchodzić w ten obszar.

  • padding: 10px — doda odstęp ze wszystkich czterech stron.
  • padding: 10px 15px — doda 10 pikseli od góry i od dołu, 15 z lewej i z prawej.
  • padding: 10px 12px 15px 14px — doda odstępy ze wszystkich stron: 10 od góry, 12 z prawej, 15 od dołu, 14 z lewej. Dokładnie w takiej kolejności (zgodnie z ruchem wskazówek zegara) zadaje się te wartości.

Ważny szczegół: obramowanie (border) rysowane jest na zewnętrznej granicy odstępu wewnętrznego, a nie ciasno wokół treści. 

.item {
  padding: 10px;                  /* wszystkie strony */
}
.item--2 {
  padding: 15px 10px;             /* góra i dół | lewo i prawo */
}
.item--3 {
  padding: 10px 12px 15px 14px;   /* góra | prawo | dół | lewo */
}

margin Odstępy zewnętrzne

margin zadaje odstępy zewnętrzne, licząc od krawędzi elementu, a nie od jego treści. Dobrze to widać w porównaniu z przykładem padding powyżej. Zapisuje się go w podobny sposób:

  • margin: 10px — odstępy zewnętrzne ze wszystkich stron.
  • margin: 10px 12px — 10 pikseli od góry i od dołu, 12 z lewej i z prawej.
  • margin: 10px 12px 10px 15px — 10px od góry, 12px z prawej, 10px od dołu, 15px z lewej.
  • margin-inline: auto — wyśrodkowanie w poziomie.
  • margin-block: auto — wyśrodkowanie w pionie.

Marginesy ujemne są potrzebne, żeby element swoją treścią nachodził na inną treść, nie przesuwając jej — na przykład margin-top: -50px.

Sklejanie marginesów. Odstępy zewnętrzne sąsiadujących elementów nie sumują się. Przeglądarka pokaże tylko margines o większej wartości, jeśli oba elementy go mają. To zachowanie nie występuje w kontenerach flex i grid — tam marginesy zawsze się sumują, dlatego do odstępów między elementami wygodniej użyć właściwości gap. 

.item {
  margin: 10px;                   /* wszystkie strony */

.item--2 {
  margin: 15px 10px;              /* góra i dół | lewo i prawo */
}
.item--3 {
  margin: 10px 12px 15px 14px;    /* góra | prawo | dół | lewo */
}
.item--center {
  margin-inline: auto;            /* wyśrodkowanie w poziomie */
}

box-sizing Model pudełkowy

Jak działa model standardowy (content-box). Ta wartość jest w przeglądarce domyślna. Logika: szerokość (width), którą podałeś, to szerokość wyłącznie wewnętrznej treści. Odstępy wewnętrzne (padding) i obramowania (border) doliczają się do tej szerokości.

Problem: tworzysz blok o width: 100%, dodajesz mu padding: 20px i blok wychodzi za krawędź ekranu, tworząc poziomy pasek przewijania. To maksymalnie niewygodne.

Jak działa model współczesny (border-box). To właśnie tę wartość ustawia u siebie niemal każdy programista. Logika: szerokość (width), którą podałeś, to ostateczna szerokość bloku. Odstępy wewnętrzne i obramowania „wciskają się” do środka, nie rozciągając bloku na zewnątrz.

Wzór: całkowita szerokość = width (już zawiera padding i border).

Zaleta: jeśli nadałeś blokowi width: 300px, pozostanie on 300px niezależnie od tego, ile odstępów wewnętrznych mu dorzucisz. Treść wewnątrz po prostu się ściśnie. 

/* Ustawiane raz, globalnie, na początku projektu */
*,
*::before,
*::after {
  box-sizing: border-box;
}

.content-box {
  box-sizing: content-box;  /* 200px + 20px paddingu + 5px ramki = 250px */
  width: 200px;
  padding: 20px;
  border: 5px solid red;
}

.border-box {
  box-sizing: border-box;   /* zawsze dokładnie 200px */
  width: 200px;
  padding: 20px;
  border: 5px solid green;
}

reset / normalize Normalizacja stylów

Do czego potrzebna jest normalizacja stylów:

  • Usunięcie rozbieżności między przeglądarkami. Każda przeglądarka (Chrome, Firefox, Safari, Edge) ma własny „styl domyślny” (User Agent Stylesheet). Na przykład jedna przeglądarka dodaje margin do list <ul>, a inna padding. Nagłówki <h1> mogą mieć różny rozmiar czcionki albo różne odstępy. Normalizacja sprawia, że Twoja strona wygląda maksymalnie tak samo wszędzie.
  • Stworzenie „czystej kartki”. Zamiast walczyć ze standardowymi odstępami, których nie dodawałeś, zerujesz je albo standaryzujesz. Pozwala Ci to budować projekt od zera, kontrolując każdy piksel.
  • Naprawa częstych błędów. Biblioteki do normalizacji (na przykład Normalize.css) często zawierają poprawki drobnych błędów przeglądarek, które nie dotyczą wprost wyglądu — na przykład renderowania elementów formularzy albo poprawnego działania znaczników HTML5 w starszych wersjach.

@font-face Podłączanie fontów

Istnieje kilka sposobów podłączenia fontów do projektu. Najprostszy z nich to podłączenie fontów hostowanych przez Google Fonts. Można to zrobić na dwa sposoby: z HTML znacznikiem <link> albo z CSS regułą @import. Trzecia możliwość to podłączenie wprost z plików projektu. Wszystkie przykłady są poniżej.

Najlepszym formatem plików fontów jest woff2. Warto też zawsze dodawać font-display: swap, żeby tekst był widoczny natychmiast, zastępczym krojem, zanim font się wczyta.

font-weight — odpowiedniki liczb i nazw:

  • 100 — Thin (Hairline) — najcieńsza odmiana
  • 200 — Extra Light (Ultra Light) — bardzo cienka
  • 300 — Light — lekka
  • 400 — Normal (Regular) — font standardowy
  • 500 — Medium — średnia (trochę grubsza niż zwykła)
  • 600 — Semi Bold (Demi Bold) — półgruba
  • 700 — Bold — gruba
  • 800 — Extra Bold (Ultra Bold) — bardzo gruba
  • 900 — Black (Heavy) — najbardziej nasycona odmiana
Uwaga na składnię: w format() nazwa formatu musi być w cudzysłowach — format("woff2"). Zapis bez cudzysłowów sprawia, że przeglądarka odrzuca całą regułę @font-face i font nigdy się nie wczytuje, bez żadnego widocznego błędu. 
<!-- 1. Przez link w HTML (najlepszy wariant dla wydajności) -->
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap">
/* 2. Przez @import w CSS — wygodne, ale wolniejsze:
   przeglądarka odkrywa font dopiero po wczytaniu arkusza. */
@import url("https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap");

/* 3. Podłączenie z plików projektu */
@font-face {
  font-family: "ScienceGothic";
  src: url("../fonts/ScienceGothic-Light.woff2") format("woff2");
  font-weight: 300;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: "ScienceGothic";
  src: url("../fonts/ScienceGothic-Bold.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "ScienceGothic", system-ui, sans-serif;
}

Podgląd tej sekcji to cała ta strona — tekst, który właśnie czytasz, jest złożony krojem ScienceGothic podłączonym trzecim sposobem.

color Kolory i ich formaty

Jest wiele różnych formatów, w których zadaje się kolor. Podstawowe to:

  • rgb — rgb(255 0 0 / 0.5), gdzie po ukośniku podaje się kanał alfa od 0 do 1, odpowiadający za przezroczystość.
  • hex — #ff0000; dopuszczalny jest też skrócony zapis trzyznakowy #f00 oraz ośmioznakowy z kanałem alfa.
  • hsl — skrót rozwija się następująco: H — hue (odcień), S — saturation (nasycenie), L — lightness (jasność). Dokładnie w tej kolejności trzeba podawać wartości: pierwsza od 0 do 360 (odcień w stopniach), druga od 0% do 100% (nasycenie), a jasność 50% to złoty środek. Kanał alfa podaje się tak samo po ukośniku: hsl(240 100% 50% / 0.5).

Ważne aspekty pracy z kolorem:

  • color: transparent — zadaje kolor przezroczysty; widoczne będzie to, co znajduje się pod elementem.
  • currentColor — jeśli blokowi nadano color: orange, a obramowaniu border: 2px solid currentColor, to obramowanie odziedziczy wartość color. Przydatne do skracania zapisów i utrzymania spójności — zmiana jednej właściwości aktualizuje wszystkie miejsca. 
.color--1 {
  border: 2px solid #ff0000;             /* hex */
}
.color--2 {
  border: 2px solid rgb(255 0 0 / 1);    /* rgb + alfa */
}
.color--3 {
  border: 2px solid hsl(0 100% 50% / 1); /* hsl + alfa */
}
.color--4 {
  color: orange;
  border: 2px solid currentColor;        /* dziedziczy wartość color */
}

rgb — rgb(255 0 0 / 1)
hsl — hsl(0 100% 50% / 1)
currentColor

background Tło i właściwości pochodne

Podstawowe właściwości:

  • background-color — kolor tła. Można podawać w hex, rgb, hsl albo nazwą.
  • background-image — ścieżka do obrazu: url("./path/to/image.jpg").
  • background-repeat — zarządza powtarzaniem tła. repeat (domyślnie) wypełnia całą powierzchnię, no-repeat wyświetla obraz jeden raz, a repeat-x / repeat-y powtarzają go tylko w poziomie albo w pionie.
  • background-position — gdzie znajduje się tło. Wartości: center, top, bottom, left, right albo w pikselach i procentach (na przykład 20px 50%).
  • background-size — rozmiar obrazu. cover rozciąga zdjęcie na cały blok bez utraty proporcji (część zdjęcia może zostać obcięta), a contain wpisuje zdjęcie w blok w całości (mogą zostać puste miejsca).
  • background-attachment — zachowanie przy przewijaniu. scroll (domyślnie) — tło przesuwa się razem ze stroną; fixed tworzy efekt paralaksy (tło zastyga, a treść jedzie po nim).

Obszar wyświetlania (background-clip). Zarządza tym, jak daleko pod granice bloku wchodzi tło:

  • border-box (domyślnie) — tło sięga pod obramowanie.
  • padding-box — tło tylko do granicy obramowania (zajmuje padding, ale nie border).
  • content-box — tło tylko tam, gdzie treść (nie wchodzi na padding).
  • text — tło wypełnia wyłącznie sylwetkę tekstu. Ważne: żeby zobaczyć efekt, tekst musi być przezroczysty (color: transparent). W Chrome i Safari potrzebny jest też prefiks -webkit-background-clip: text.

Zapis skrócony (shorthand). Wszystkie te właściwości można zapisać w jednym wierszu jako background. Kolejność nie jest ścisła, ale background-size ma niuans — pisze się go po ukośniku, za pozycją:

Kolor | Obraz | Pozycja / Rozmiar | Powtarzanie | Przywiązanie
background: #f00 url("cat.jpg") center / cover no-repeat fixed; 

.background-example {
  color: wheat;
  background: #2e5cb8;
  border: 1px solid black;
}

/* Zapis skrócony ze wszystkimi wartościami */
.hero {
  background: #f00 url("cat.jpg") center / cover no-repeat fixed;
}

/* Tło tylko w sylwetce tekstu */
.gradient-text {
  background-image: linear-gradient(90deg, #2e5cb8, greenyellow);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
}

outline Obramowanie zewnętrzne

outline to właściwość podobna do border. Zapis odbywa się na tej samej zasadzie — grubość, styl, kolor. Różnica polega na tym, że outline ma dodatkowo właściwość outline-offset, czyli przesunięcie obramowania do środka (proporcjonalnie zmniejszając je) albo na zewnątrz (proporcjonalnie zwiększając).

Druga istotna różnica: outline nie zajmuje miejsca w układzie strony — nie przesuwa sąsiednich elementów i nie zmienia rozmiaru bloku, w przeciwieństwie do border. Dlatego właśnie przeglądarki używają go do zaznaczania fokusu.

Nigdy nie usuwaj outline bez zamiennika. Zapis outline: none na elementach interaktywnych sprawia, że osoby korzystające z klawiatury nie widzą, gdzie się znajdują. Jeśli domyślny styl nie pasuje, nadpisz go własnym w :focus-visible. 
.outline {
  outline: 2px solid red;
}
.outline-offset-minus {
  outline: 2px solid red;
  outline-offset: -10px;   /* do środka */
}
.outline-offset-plus {
  outline: 2px solid red;
  outline-offset: 5px;     /* na zewnątrz */
}

/* Poprawny sposób na własny styl fokusu */
.button:focus-visible {
  outline: 3px solid #2e5cb8;
  outline-offset: 2px;
}

Podgląd

outline: 2px solid red
outline-offset: -10px
outline-offset: 5px

border-radius Zaokrąglanie narożników

border-radius może zrobić element okrągłym albo po prostu zaokrąglić jego narożniki. Wartość 50% zamienia kwadrat w koło.

Można też tworzyć ciekawe figury, podając parametry po kolei, zaczynając od lewego górnego narożnika i idąc zgodnie z ruchem wskazówek zegara aż do lewego dolnego.

Poniżej podane są trzy przykłady: gdzie narożniki zostały po prostu zaokrąglone, gdzie zostały zaokrąglone do koła (czyli 50%) oraz gdzie każdemu narożnikowi nadajemy własną wartość. 

.border-radius--1 {
  border-radius: 5px;                /* wszystkie narożniki */
}
.border-radius--2 {
  border-radius: 50%;                /* koło */
}
.border-radius--3 {
  border-radius: 5px 10px 50% 10px;  /* lewy górny | prawy górny | prawy dolny | lewy dolny */
}

Podgląd

border-radius: 5px
border-radius: 50%
5px 10px 50% 10px

box-shadow Cień pudełka

Przykład zapisu i znaczenie kolejnych wartości:

  • pierwsza wartość odpowiada za przesunięcie w prawo albo w lewo (minus — w lewo, plus — w prawo);
  • druga wartość odpowiada za przesunięcie w dół albo w górę (minus — w górę, plus — w dół);
  • trzecia wartość, na przykład 6px, odpowiada za promień rozmycia;
  • czwarta wartość odpowiada za rozprzestrzenienie cienia (spread);
  • piątą wartością jest kolor. W zapisie rgb czwarta liczba, po ukośniku, to nasycenie koloru, czyli przezroczystość (opacity);
  • przy słowie kluczowym inset cień będzie rozprzestrzeniał się do środka elementu.

Cieni można podać kilka, rozdzielając je przecinkami — tak buduje się bardziej naturalne, miękkie cienie w interfejsach. 

.box-shadow-example {
  /* przesunięcie X | przesunięcie Y | rozmycie | rozprzestrzenienie | kolor | inset */
  box-shadow: -5px 10px 6px 5px rgb(0 0 255 / 0.5) inset;
}

/* Kilka cieni naraz — tak buduje się miękkie cienie w interfejsach */
.card {
  box-shadow:
    0 1px 2px rgb(0 0 0 / 0.08),
    0 4px 12px rgb(0 0 0 / 0.12);
}

filter Filtry graficzne

Filtry nakładane na obrazy:

  • brightness — jasność obrazu. Domyślnie 1; wartość można podać także w procentach.
  • blur — wartość podaje się w pikselach; od 0 w górę efekt rozmycia się nasila.
  • contrast — kontrast.
  • drop-shadow — można nadać cień bezpośrednio sylwetce obrazu PNG, a nie prostokątowi jego krawędzi. Ciekawe zastosowanie.
  • grayscale — sprawia, że obraz staje się czarno-biały.
  • saturate — zmienia nasycenie kolorów.
  • sepia — dodaje brązowy odcień, jak na starych zdjęciach.
  • opacity — przezroczystość, od 0 do 100%.

Filtry można łączyć w jednej deklaracji, wypisując je po spacji: filter: grayscale(50%) blur(1px). Kolejność ma znaczenie, bo każdy filtr działa na wynik poprzedniego. 

.box--1 img {
  filter: brightness(0.5);
}
.box--2 img {
  filter: blur(1px);
}
.box--3 img {
  filter: drop-shadow(15px 15px 15px red);
}
.box--4 img {
  filter: grayscale(50%);      /* od 0 do 100 procent */
}
.box--5 img {
  filter: opacity(50%);        /* od 0 do 100% — przezroczystość */
}
.box--6 img {
  filter: saturate(0.5);       /* od 0 w górę */
}

/* Filtry można łączyć — kolejność ma znaczenie */
.box--combo img {
  filter: grayscale(100%) blur(2px);
}
